MY DAILY TODO - ANDROID APP (free cloud build, no Android Studio needed)

1. Create a free account at github.com and make a NEW repository (any name).
2. On a computer: open the repository > Add file > Upload files. Drag ALL files and folders
   from this project (including the hidden ".github" folder) and click Commit.
3. Open the "Actions" tab > "Build APK" > "Run workflow". Wait ~5 minutes.
4. Open the finished run > "Artifacts" > download MyDailyTodo-APK, unzip it.
5. Copy app-debug.apk to your phone, open it and allow "Install unknown apps".
6. In the app: tap "Enable notifications", allow the permission, choose interval + tune.
7. Also on Android: Settings > Apps > My Daily Todo > Battery > "Unrestricted",
   so reminders are not delayed.
